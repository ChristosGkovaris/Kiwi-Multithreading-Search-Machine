
# Changelog

All notable changes to the Kiwi Multithreaded Storage Engine
are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

## [1.0.0-alpha.1] - 2026-11-25

### Added

- Conceptual system architecture diagram.
- Structured technical documentation for concurrency and
  synchronization mechanisms.
- Performance evaluation methodology.
- Development roadmap.
- Documentation of project limitations and verification requirements.

### Changed

- Restructured the README to improve technical clarity and readability.
- Improved repository description and technology classification.
- Consolidated build and execution instructions.
- Standardized academic attribution and author information.

## [1.0.0] - Initial public version

### Added

- Experimental multithreaded storage engine implemented in C.
- POSIX thread-based workload execution.
- Mutex and condition-variable synchronization mechanisms.
- Reader-writer coordination.
- Configurable read, write, and mixed benchmark workloads.
- Execution time measurement and benchmark logging.
- Project documentation and contribution guidelines.

### Known Limitation

- Reproducible builds require verification.
- Concurrency correctness requires further validation.
- Automated regression testing is not yet established.
- Performance results have not been independently validated.
